# CarboLens UAE — Enhanced Mac Prototype

This version adds:
- Animated/modern dashboard styling
- AI Alternatives Finder with transparent ranking
- Carbon reduction + cost + availability trade-offs
- AI Design Checker demo
- Project reporting

## Run

```bash
cd ~/Downloads/CarboLens_UAE
source .venv/bin/activate
streamlit run app.py
```

## Important
The carbon factors are illustrative demo values. They are not verified UAE EPD/LCA data.
The "AI" recommendation engine is a transparent prototype ranking model. A production
CarboLens system would connect to verified carbon data, suppliers, project specifications,
and a real AI/BIM/CAD processing pipeline.
